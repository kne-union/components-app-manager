把应用中心里某个应用的菜单页面嵌入宿主页面（通常是租户端左菜单右侧的内容区）。宿主只需要提供路由，页面如何加载、鉴权由组件处理。

- **远程组件优先**：`integration=remote` 的应用，直接加载子应用的 `ComponentPreset` 与菜单页面组件，与宿主共用同一个 React 与路由；iframe、新窗口作为降级
- **用户级令牌**：向应用中心申请以当前登录用户、当前租户签发的令牌，只放内存，到期前自动刷新，`401` 时强制刷新
- **只渲染有权限的菜单**：菜单来自应用中心的 `centerMenus`（已按租户展示设置、租户开通与用户权限裁剪），找不到应用或菜单时给出提示
- **应用挂了的状态检测**：页面照常渲染，进入后异步向应用中心查一次应用状态（`centerStatus`）；正常什么都不做，不正常再切换成错误状态，可重新检测。检测请求本身失败不打断页面；应用挂了时菜单沿用应用中心缓存的上一份快照，入口不会消失
- **版本变化提示**：联邦入口加载后无法热替换，应用升版本后提示用户刷新页面
